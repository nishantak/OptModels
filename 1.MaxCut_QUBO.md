# 1. MaxCut optimisation using QUBO

## MaxCut - Problem:

Given an undirected, weighted graph $G = (V, E, w)$, with $W_{ik} > 0$, choose a partition $S$, $\bar{s}$, that maximises the sum of the weights on the edges crossing the cut.

Indicator function for the cut using sping variables, $z \in \{-1, +1\}$,

$$
I(i, k) = \frac{1 - z_{i}z_{k}}{2} =
\begin{cases}
0: & \text{i, k in same side} \\
1: & \text{i, k in different side}
\end{cases}

$$

$\implies$ Cut value,

$$
Cut(z) = \sum_{\{i, k\} \in E}{w_{ik} I(i,k)} = \frac{1}{2}\sum_{\{i, k\} \in E}{w_{ik} (1 - z_iz_k)}
$$

%% [markdown]
##Goal:

Maximise the cut value, 

$$
max(Cut(z))
$$

We have,

$$
Cut(z) = \underbrace{\frac{1}{2} \sum_{\{i,k\} \in E}{w_{ik}}}_{\text{cosntant}} - \frac{1}{2} \sum_{\{i,k\} \in E}{w_{ik}z_iz_k}
$$

Therefore,

the cost of this function, $C(z)$, depends on 

$$
C(z) = - \frac{1}{2} \sum_{\{i,k\} \in E}{w_{ik}z_iz_k}
$$

which we need to minimise.

Optimisation of this problem is an NP-Hard problem. (Polynomial-time approximations exist. e.g., Goemans-Williamson's 0.878-approximation)

## Quadtratic Unconstrained Binary Optimisation (QUBO) - Formulation:

- Variables: $x_i \in {0,1}$ : **Binary**
- Cost: $C(x)=x^{T}Qx$, for some real matrix $Q$: **Quadratic**
- Constraints: No constraints other than binary domain : **Unconstrained**
- Goal: minimize $C(x)$ : **Optimisation**

## MaxCut as QUBO

**Why?** To process it using Ising solvers, annealers, QAOA preprocessors

**How,**

Spin --> Binary

$$
z_i = 2x_i - 1 \quad x_i \in \{0,1\}
$$

Then,

$$
z_iz_k = (2x_i - 1)(2x_k -1) = 4x_ix_k - 2x_i - 2x_k + 1
$$

Removing the constants (QUBO is assumed upto a constant term) and plugging in $Cut(z)$,

$$
Cut(z) = Cut(x) = \frac{1}{2} \sum_{\{i,k\} \in E}{w_{ik}(1 - (4x_ix_k - 2x_i - 2x_k + 1))} = \sum_{\{i,k\} \in E}{w_{ik}(x_i + x_k - 2x_ix_k)}
$$

##Goal:
$$
\max{(Cut(x))}.
$$

Expand:

$$
Cut(x) = \underbrace{\sum_{\{i,k\}\in E}{w_{ik}(x_i + x_k)}}_{\text{linear}} \quad - \quad \underbrace{2\sum_{\{i,k\}\in E}{w_{ik}x_ix_k}}_{\text{quadratic}}
$$

Standard QUBO is a minimisation problem. So, 

**Goal:** 
$$
\min_x{-Cut(x)}
$$

### QUBO matrix Q

QUBO: 

$$
\min_{x\in\{0,1\}^n} x^TQx = \sum_i{Q_{ii}x_i^2} + 2\sum_{i<k}{Q_{ik}x_ix_k}
$$

Take,
$$
-Cut(x) = -\sum_{{i,k}\in E} w_{ik}(x_i + x_k - 2x_ix_k) = -\sum_{{i,k}\in E} w_{ik}x_i -\sum_{{i,k}\in E} w_{ik}x_k + 2\sum_{{i,k}\in E} w_{ik}x_ix_k.
$$

Then,

Linear Terms (diagonal elemnts $ik$):
$$
-\sum_{{i,k}\in E} w_{ik}x_i -\sum_{{i,k}\in E} \quad = \quad - \sum_{k:\{i,k\}\in E}{w_{ik}x_i} = \sum_i{Q_{ii}x_i^2} \quad (x^2 = x \text{ in binary})
$$

$$
Q_{ii} = -\sum_{k:\{i,k\}\in E}{w_{ik}}
$$

Quadratic Terms:

$$
2\sum_{\{i,k\}\in E} w_{ik}x_ix_k = 2\sum_{i<k}{Q_{ik}x_ix_k} \\
$$
$$
Q_{ik} = 
\begin{cases}
w_{ik}: & i \neq k, \{i,k\} \in E \\
0: & \text{otherwise}
\end{cases}
$$

## Solver (BLS + Tabu)
The solver is a **tabu-guided 1-flip local-search with breakout perturbation** for Max-Cut on an Ising (spin) formulation.

```
Initialize spins s randomly
Compute t[i] = Σ w_ij s[j]
Compute g[i] = s[i] * t[i]
Initialize best_s, best_cut
Initialize tabu times

Repeat for N iterations:
    Select admissible move i with max gain g[i]
        (tabu may be overridden by aspiration)
    Flip s[i], update t[j], g[j], tabu, heap
    If new cut > best_cut, save and reset plateau counter
    Else plateau_counter += 1
    If plateau_counter >= plateau:
         perform breakout by flipping k worst g[i]
         update t, g, tabu
         reset plateau_counter

Return best_s, best_cut
```

### Spin encoding

We represent each vertex (i) by a spin variable
$$
s_i \in \{-1, +1\}
$$
which determines to which side of the cut the vertex belongs.

For an undirected weighted graph $G((V,E,w))$, Max-Cut is
$$
Cut(s)= \frac12 \sum_{{i,j}\in E} w_{ij}(1 - s_i s_j)
$$

If $s_i \ne s_j$, the edge contributes $w_{ij}$.
If $s_i = s_j$, the edge contributes $0$.

The additive constant
$$
\frac12\sum_{{i,j}} w_{ij}
$$
is fixed, so maximizing the cut is equivalent to maximizing
$$
-\frac12\sum_{{i,j}} w_{ij} s_i s_j
$$
or minimizing the Ising energy
$$
H(s) = -\sum_{{i,j}} w_{ij} s_i s_j .
$$

### Gain-based local move model

If we flip a single vertex $i$: $s_i \gets -s_i$,
the change in cut value is
$$
\Delta_i = \sum_{j:{i,j}\in E} w_{ij} s_is_j 
$$

The solver precomputes
$$
t_i = \sum_{j} w_{ij} s_j
$$
so that
$$
\Delta_i = s_i t_i.
$$

Thus, selecting a move is reduced to picking the $i$ with largest positive $\Delta_i$.

To keep this fast, whenever a spin is flipped, $t_j$ is updated incrementally only for neighbors of $i$. This avoids recomputing the objective from scratch at every step.

We store
$$
g_i = s_i t_i = \Delta_i
$$
so the priority structure can directly rank candidate moves.

### Tabu search 
Local search can cycle: the best next move might simply undo the previous flip.A **tabu list** prevents immediate return.

Each vertex $i$ has a time until which it is forbidden to flip again.
This *tabu tenure* is randomized in the range $[t_{\min}, t_{\max})$.

If a vertex is tabu but flipping it produces a strictly better solution than the global best so far, the tabu restriction is **overridden** (aspiration rule).

This allows progress through high-value improving moves while discouraging neutral or regressive cycles.

### Move selection via priority queue

The algorithm uses a max-heap keyed by $-g_i$ (“largest gain first”).
Because gain updates happen incrementally, entries can become stale.
To handle this, we attach a per-vertex version counter and discard stale entries popped from the heap.

### Updating after a move

When vertex (i) is flipped:

1. $s_i \gets -s_i$.
2. Current cut value is incremented by $g_i$.
3. $i$ receives a new tabu expiry.
4. For each neighbor $j$,
   $$
   t_j \gets t_j + 2w_{ij}s_i
   $$
   so
   $$
   g_j = s_j t_j
   $$
   is updated.
5. Finally, $g_i \gets -g_i$, because flipping the sign reverses $s_i$ but leaves $t_i$ consistent.

These incremental updates make the method fast—only affected vertices are updated.

### Best-so-far tracking
Along the walk, the solver tracks:
* **current state** (local optimum region)
* **best state encountered** (global record)
Whenever a flip exceeds the best-so-far cut, the global record is updated and all stagnation counters reset.

### Breakout (diversification)
A pure tabu walk sometimes stagnates in a strong local basin. To escape, the solver uses **breakout local search (BLS)**:

If there is no improvement for `plateau` iterations --> a **perturbation** is applied.

This perturbation flips the $k$ vertices with the lowest gain values $g_i$. These are the vertices contributing least to the current cut, so flipping them is a reasonable way to weaken the current configuration and explore a new basin.

After perturbation, tabu restrictions are assigned to these vertices, and search resumes normally.

Due to computational limits, the results confirm that the run budget is tiny and breakout rarely fires, so the search stays near its first local optimum. Toshiba’s solver spends more search effort per instance and reaches or matches best-known cuts.

Our cuts are ~1–2% below best_known on most instances while times are consistently low (0.03–0.37 s). Toshiba_time jumps to multi-second on some cases (e.g., G14 ≈10 s) but almost always achieves best_known.

Time per flip is asymptotically O(dlog⁡n) due to heap updates for each affected vertex. For sparse G-set graphs this is fine; for denser graphs cost grows.

One initial state limits coverage. Multi-start or long single runs scale quality but cost time.

Toshiba is fast because it does special-purpose physics-based parallel search (Simulated Bifurcation) on highly optimized hardware
